# LINUX INFRASTRUCTURE ADMINISTRATOR

## Professional Summary

Linux systems and network administrator with more than 15 years of hands-on IT experience designing, securing, and supporting infrastructure in higher education, government, and small-business environments. Experienced in Linux and BSD UNIX administration, centralized identity and authentication, KVM virtualization, mdadm and LVM storage management, VLANs, firewalls, VPNs, monitoring, backup and recovery, and Bash-based automation. Designed and supported multi-user environments using OpenLDAP, Kerberos, PAM, Samba, OpenBSD, FreeBSD, PF, pfSense, OpenVPN, Nagios/Icinga, and Bacula. Currently completing an Associate of Applied Science in Cybersecurity and Network Systems while strengthening skills in infrastructure security, vulnerability management, threat detection, and incident response.

## Core Qualifications

* Linux and BSD UNIX systems administration
* Centralized identity, authentication, and access management
* OpenLDAP, Kerberos, PAM, Samba, SSO, and OAuth
* KVM/libvirt virtualization and virtual machine administration
* Linux storage administration using mdadm software RAID and LVM
* TCP/IP, VLANs, DNS, DHCP, firewalls, NAT, and VPNs
* PF on OpenBSD, pfSense, and OpenVPN administration
* Network file shares, backup, recovery, and restore testing
* Bash automation, cron, rsync, and Python fundamentals
* Nagios/Icinga monitoring, SNMP, and operational alerting
* Network segmentation, system hardening, and access control
* Technical documentation and independent infrastructure ownership

# Professional Experience

## Co-Owner / Linux Systems & Network Administrator

### Worker-Owned Restaurant Corporation | Athens, Ohio | 2004–2013

Designed, administered, secured, and supported the organization’s Linux-based server, network, identity, email, virtualization, monitoring, storage, and backup infrastructure for approximately 90 users.

* **Linux Administration:** Administered Linux servers and approximately 20 centrally managed Linux workstations, including system configuration, authentication, access control, patching, troubleshooting, and lifecycle support.
* **Linux and Open-Source Migration:** Led an organization-wide migration from Windows and Microsoft Office to Linux and OpenOffice.org. Implemented Linux Terminal Server Project (LTSP) infrastructure to centrally manage workstations, improve stability, reduce endpoint vulnerabilities, and avoid substantial licensing costs.
* **Identity and Access Management:** Implemented centralized identity and authentication using OpenLDAP, Samba, Kerberos, and PAM. Provided Single Sign-On (SSO) across Linux workstations and internal applications and supported Google Apps integration through OAuth.
* **Virtualized Infrastructure:** Deployed and administered an on-premises KVM/libvirt virtualization environment hosting critical business, development, email, monitoring, and infrastructure services.
* **Storage Administration:** Configured and administered Linux storage using mdadm software RAID and Logical Volume Manager (LVM), supporting server storage, network file shares, and business-critical services.
* **Network Infrastructure:** Designed and implemented network infrastructure that included structured cabling, managed wireless networks, VLAN segmentation, routing, DNS, and secure connectivity between organizational locations.
* **Firewall Administration:** Deployed and administered PF on OpenBSD and pfSense firewalls, including firewall rule management, traffic filtering, network segmentation, and NAT.
* **VPN Connectivity:** Extended secure connectivity to remote offices using OpenVPN.
* **DNS Security:** Enforced organization-wide DNS filtering through OpenDNS, now Cisco Umbrella, to block access to known malicious and phishing domains.
* **Monitoring and Operations:** Implemented infrastructure monitoring and alerting using Icinga/Nagios and SNMP, supporting proactive troubleshooting, capacity planning, availability management, and operational visibility.
* **Backup and Recovery:** Designed and automated cross-platform backup workflows using Bash, rsync, cron, Cygwin, SSH public-key authentication, host-key validation, restricted backup accounts, and Bacula. Tested restores to verify recoverability.
* **Email Infrastructure:** Deployed and administered Linux-based email services using Postfix, Dovecot, Amavisd-new, ClamAV, and SpamAssassin, along with GNU Mailman mailing lists.
* **Email and DNS Security:** Managed SPF, DKIM, DNS blocklists, and MX/PTR records to support email delivery and reduce spam and malicious messages.
* **Cloud Services Migration:** Migrated organizational email to Google Apps, mailing lists to Google Groups, and Samba-based file shares to Google Drive while preserving group-based access controls.
* **Web and Business Systems:** Developed and maintained a WordPress-based website and e-commerce platform supporting event promotion, online sales, and PCI-compliant payment processing.
* **Infrastructure Ownership:** Independently managed infrastructure priorities, troubleshooting, upgrades, security controls, and technical documentation in a small organizational environment.
